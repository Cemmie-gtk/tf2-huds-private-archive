HEY YOU, YES YOU, THANK YOU FOR DOWNLOADING MY HUD. Check for updates and more stuff soon.


Installing this is pretty simple, just put the "resource" and "scripts" folder in your *\Program Files\Steam\steamapps\youraccount\team fortress 2\tf* folder and overwrite everything. If you had a custom HUD before, PLEASE remove it before putting this one in. You can do it by simply deleting your "resource" and "scripts" folder.


That's about it. Have fun and please report any issue on the google project page at http://code.google.com/p/wadehud/
